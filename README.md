# Academy-Dashboard

A polished academy dashboard for Beyond Marks AI Academy, built with Next.js, React, and TypeScript.

## Features

- Branded navy-and-gold welcome and authentication experience
- Responsive learner dashboard and animated navigation sidebar
- Notification center with detailed message dialogs
- API access requests and secure API-key presentation
- Project workspace with working and finished project states
- GitHub repository linking and uploaded `README.md` rendering
- GitHub-Flavored Markdown support for images, tables, task lists, links, and code
- Responsive layouts and reduced-motion accessibility support

## Getting started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production build

```bash
npm run build
npm start
```

## Technology

- Next.js 16
- React 19
- TypeScript
- React Markdown with GitHub-Flavored Markdown
